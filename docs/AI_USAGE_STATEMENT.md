## 本项目使用腾讯 WorkBuddy 作为开发辅助工具

WorkBuddy 是本届赛事的官方合作伙伴。以下说明本项目在开发过程中如何使用 AI，以及**主动披露 AI 辅助过程中暴露并修复的问题**。

## 一、开发方式

- 创意构思、Skill 规则设计、技术选型、实测验证、缺陷修复与最终决策，均由参赛者完成并承担责任
- WorkBuddy 承担编码辅助、接口调试、文档撰写、测试执行等工作
- 全部代码、文档、测试数据均经过参赛者逐项复核后提交

## 二、主动披露：AI 辅助过程中暴露的问题

本项目的核心价值恰恰来自 AI 辅助过程中被识别并修复的问题。以下三类问题均已修复，并固化为 `SKILL.md` 中不可违背的铁律，同时在 `TEST_REPORT_FINAL.md` 中如实记录：

| 问题 | 性质 | 修复方式 |
| --- | --- | --- |
| 将工具入参回显的锚点距离输出为「距你 144 米」 | 参数幻觉 | 新增「AI 没有 GPS」专章，禁用表述对照表 + 强制能力边界自白 |
| 未经用户确认即调用领券等写操作 | 越权 | 新增「写操作确认」专章，写操作一律先展示影响面并等明确确认 |
| 将接口返回的券播报为「你有 N 张券」 | 数据归属误判 | 收紧口径为「接口返回 N 张」，不替用户断言资产归属 |

**我们认为，主动披露并解决 AI 幻觉问题，比隐藏它更能体现工程价值。** 相关完整记录见 [`BLOG_ARTICLE.md`](../BLOG_ARTICLE.md) 与 [`TEST_REPORT_FINAL.md`](../TEST_REPORT_FINAL.md)。

## 三、测试与验证

- 记忆算法：8 项离线测试全绿，脚本见 [`test_memory.py`](../test_memory.py)
- 主链路：6 盒实跑，覆盖城市/门店/活动/抽奖/菜单/记忆全流程
- 商业闭环：积分抽奖（194 → 170）→ 中奖券在用户小程序确认到账 → 券抵扣试算（原价 ¥50.50 → ¥32.30，实测省 ¥18.20）
- 凭证安全：全 git 历史扫描零命中，配置仅使用环境变量占位符
